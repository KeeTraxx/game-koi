## What is this

`game-koi` is a Game Boy emulator core written in Rust as a learning exercise, with a
desktop build (winit/pixels/cpal/gilrs) and a browser build compiled to WebAssembly and
published to npm as the `game-koi` package. This site documents the npm package and
shows it running.
