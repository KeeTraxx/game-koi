## The code

The component is almost line for line the [React example](../react/). The differences
are Preact's own:

- **Hooks come from `preact/hooks`**, and the event type is Preact's `TargetedEvent`.
- **Plain `class` works.** Preact passes attributes through to the DOM as written, so
  `className` is optional.
- **`onChange` is the DOM's native `change` event**, not React's synthetic one. For a
  file input the two behave the same.
- **The `@jsxImportSource preact` pragma** is only needed because this site also has
  React components. In a Preact-only project, your `tsconfig.json` sets it once.

As in React, the emulator lives in a ref, `create` runs in the change handler (browsers
only start audio from a user gesture), the effect's cleanup calls `dispose()`, and
`game-koi` is imported lazily so it never loads during a server-side render.
