`game-koi` is the browser build of the emulator: a WebAssembly module wrapped in a small
TypeScript API that handles canvas rendering, audio, frame pacing and input for you.
Every example on this site uses the same API, so start here even if you use a framework.

```sh
npm install game-koi
```

## The code

You need a 160×144 canvas and the ROM's bytes as a `Uint8Array`. `GameKoi.create` does
the rest. Call it from a user gesture (a click or a file pick), since browsers keep a
freshly created `AudioContext` suspended otherwise.

## Beyond the basics

A `GameKoi` instance also has `pause()`, `resume()`, `press()`/`release()` for on-screen
buttons, `on('press' | 'release', ...)` events, and `dispose()` to shut it down. The
keyboard map, gamepad map and debug overlay key are all options to `create`. The
package's own README documents every one of them:
[`crates/game-koi-web/js/README.md`](https://github.com/KeeTraxx/game-koi/blob/main/crates/game-koi-web/js/README.md).
