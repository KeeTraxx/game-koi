`game-koi` is a Game Boy emulator written in Rust. Its browser build is published to
npm as the `game-koi` package: give it a canvas and a ROM, and it handles rendering,
audio, frame pacing, keyboard and gamepad input.

```sh
npm install game-koi
```

## Examples

Every example below is running on its page. Bring your own `.gb` ROM.
