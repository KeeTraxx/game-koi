## The code

Things specific to Svelte:

- **`bind:this`** gives the component the canvas element to hand to `GameKoi.create`.
- **`koi` is a plain variable, not `$state`.** The markup never reads it, so making it
  reactive would only add a proxy around the emulator.
- **`game-koi` is imported inside the handler.** The package touches `AudioContext`
  and wasm as soon as it is evaluated, so it must not load during SvelteKit's (or
  Astro's) server-side render. The `import type` at the top is erased at compile time
  and is safe.
- **`onDestroy` calls `dispose()`**, which stops the frame loop, removes the keyboard
  listeners and closes the audio context.
