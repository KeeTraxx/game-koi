## The code

Things specific to Vue:

- **`useTemplateRef('canvas')`** (Vue 3.5+) gives the component the canvas element to
  hand to `GameKoi.create`. On older versions, use `ref<HTMLCanvasElement | null>(null)`
  with a variable of the same name.
- **`koi` is a plain `let`, not a `ref()`.** The template never reads it, and a
  reactive proxy around the emulator would add nothing.
- **`game-koi` is imported inside the handler.** The package touches `AudioContext`
  and wasm as soon as it is evaluated, so it must not load during a server-side render
  (Nuxt, Astro). In Nuxt you can also wrap the component in `<ClientOnly>`.
- **`onBeforeUnmount` calls `dispose()`**, which stops the frame loop, removes the
  keyboard listeners and closes the audio context.
